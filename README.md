# Пульт

Внук нажимает «Помочь бабушке» — у неё всплывает **одна большая кнопка «Разрешить»**,
и он видит её экран.

Два приложения, связанные в пару, плюс сервер, который только сводит их друг с другом.
Содержимое экрана идёт напрямую между телефонами, зашифрованное; сервер его не видит и не хранит.

Исходное ТЗ — [`babushka.md`](babushka.md). Документация — в [`docs/`](docs/).

## Быстрый старт (локально, без телефонов)

```bash
cd server && npm install && npm start        # сигналинг на http://localhost:8080
```

1. Открыть `http://localhost:8080/panel/?role=grandma` → «Создать пару (стенд)».
2. Скопированную ссылку открыть во второй вкладке — это панель внука.
3. Внук жмёт «Помочь бабушке» → у «бабушки» всплывает «Разрешить» → идёт показ экрана
   (в стенде — через `getDisplayMedia`), работает указатель, «Стоп» и гашение
   «банковского приложения».

Проверка пары (HMAC с привязкой к отпечаткам DTLS) в стенде настоящая — протокол
можно гонять до появления телефонов.

## Тесты

```bash
cd server && npm test        # 43 теста: маршрутизация, лимиты, журнал, векторы
cd web    && npm test        #  9 тестов: крипто пары в Web Crypto
cd android && ./gradlew testDebugUnitTest assembleDebug   # 31 тест + два APK
```

Android требует Android SDK (platform 36) и JDK 17+; сборка проверена на Gradle 9.1 + JDK 24.

## Что уже готово, а что нет

| Часть | Состояние |
|---|---|
| Протокол, документация, ADR | готово |
| Сигналинг: комнаты, присутствие, маршрутизация, лимиты, журнал, TURN-креды | работает, покрыто тестами |
| Веб-панель + стенд бабушки | работает в браузере |
| Общие тест-векторы пары (Node / Web Crypto / Kotlin) | сходятся |
| Android: `core` — протокол, крипто, клиент сигналинга, машина состояний | готово, 31 тест |
| Android: приложения бабушки и внука | собираются в APK |
| Android: WebRTC поверх libwebrtc — захват экрана, приём, указатель, гашение | код есть, компилируется; на устройствах не прогонялся |
| NFC/QR-спаривание на устройствах, белый список в бою | не проверено на железе |

## Три правила, которые не обсуждаются

1. **Скрытого режима не существует.** Приложение бабушки всегда видно: постоянное
   уведомление, обычная иконка, рамка во время сессии. Невидимый доступ к чужому
   устройству — это stalkerware: бан в сторе и правовой риск. Никогда, ни по чьей просьбе.
2. **Без нажатия «Разрешить» доступа нет.** Запрос помощника — это только вопрос.
   Доступ выдаётся на сессию, не навсегда, и опции «разрешать всегда» не существует.
   Чтобы помощь не превращалась в назойливость — лимит запросов и тихие часы.
3. **Секрет пары не покидает устройства.** Спаривание только вблизи (NFC/QR при встрече),
   сервер секрета не знает и подменить собеседника не может.

Подробности и обоснование — [docs/security.md](docs/security.md).
