# Приложение внука и веб-панель

У помощника два клиента, равноправных по протоколу: Android-приложение и веб-панель.
Веб-панель — не урезанная версия, а полноценный клиент; она же служит отладочным стендом
и позволяет проверять протокол без двух телефонов.

Модуль: `android/helper`, пакет `ru.pult.helper`. Веб: `web/`.

---

## 1. Что видит помощник

| Состояние | Что на экране |
|---|---|
| Пара не настроена | «Настройте помощь при встрече» + мастер спаривания (NFC/QR) |
| Бабушка не в сети | серый индикатор, время последнего контакта: «была в сети 2 часа назад» |
| Бабушка в сети | зелёный индикатор + большая кнопка **«Помочь бабушке»** |
| Запрос отправлен | «Ждём, пока бабушка нажмёт „Разрешить“» + отсчёт 90 с + «Отменить» |
| Отказ / нет ответа | «Бабушка сейчас не может» — нейтрально, без давления и без «попробовать ещё раз» крупной кнопкой |
| Сессия | экран бабушки, инструменты указателя, «Завершить» |
| Лимит исчерпан | «Вы уже отправили 5 запросов за час» + когда можно снова |

Формулировки отказа — нейтральные. Интерфейс не должен подталкивать помощника
давить на бабушку: «Не дозвонились? Позвоните ей!» — это уже социальная инженерия
руками продукта.

## 2. Инструменты во время сессии

- **Указатель**: клик/тап по картинке экрана → `pointer{kind:"tap"}`; обвод пальцем/мышью →
  `pointer{kind:"circle"}`. Координаты в долях (0..1), пересчёт от размеров видео, а не окна.
- **Подпись**: короткая фраза (≤ 60 символов) на экран бабушки — `say`. Пресеты:
  «Нажмите сюда», «Прокрутите вниз», «Всё верно».
- **Завершить**: `stop` + `session-end{reason:"stopped-by-helper"}`.
- Кнопок «сделать за неё» в V1 нет. Управление — V2, отдельный модуль
  ([roadmap.md](roadmap.md)).

Что помощник **не может** технически: включить показ без согласия, отключить рамку и
уведомление у бабушки, снять гашение банковского приложения, продлить доступ за пределы сессии,
записать экран (кнопки записи нет; запись экрана самим устройством помощника вне нашего контроля,
но и не поощряется интерфейсом).

## 3. Веб-панель (`web/`)

Статика, без сборки: HTML + ES-модули + `RTCPeerConnection`. Раздаётся сигналинг-сервером
на `/panel/`.

```
web/public/
├── index.html          панель помощника
├── app.js              состояние, WS-клиент, WebRTC
├── protocol.js         типы и MAC (Web Crypto), общая логика с сервером
├── pairing.js          чтение QR через камеру, хранение пары
└── style.css           крупная типографика, тёмная тема по умолчанию
```

Хранение пары: `pairSecret` импортируется как **non-extractable** `CryptoKey` (HMAC-SHA256)
и лежит в IndexedDB — из JS его нельзя прочитать, только использовать для подписи.
Это заметно лучше, чем `localStorage` со строкой, но всё же слабее Keystore: для постоянного
использования рекомендуем Android-клиент, веб — для «я за компьютером, помогу отсюда».

Отладочный режим: `?role=grandma` открывает вкладку-заглушку бабушки, отдающую
`getDisplayMedia()` вместо MediaProjection. Весь сценарий 1-2-3 проигрывается в браузере,
включая проверку MAC — удобно для разработки протокола до появления устройств.

## 4. Android-приложение помощника

```
ru.pult.helper/
├── HelperApp.kt
├── PresenceService.kt      лёгкий сервис: presence + FCM, без захвата экрана
├── ui/
│   ├── MainActivity.kt     состояние пары, «Помочь бабушке»
│   ├── SessionActivity.kt  видео + указатель
│   ├── JournalActivity.kt  журнал сессий (общий для семьи)
│   └── PairingActivity.kt  NFC-чтение / сканер QR
└── data/PairStore.kt       EncryptedSharedPreferences
```

- Приложение помощника **не** требует ни overlay, ни UsageStats, ни MediaProjection —
  и просить их не должно.
- FCM: помощник получает push «бабушка снова в сети», «сессия завершена», «телефон бабушки
  не выходит на связь больше 6 часов».
- Видео рендерится в `SurfaceViewRenderer` (WebRTC), с сохранением пропорций и без
  масштабирования выше 1:1 — иначе координаты указателя разъезжаются.

## 5. Журнал для всей семьи

Экран журнала показывает: дату, кто запросил, ответ бабушки (разрешила / отказала /
не ответила), длительность, было ли гашение банковского приложения. Данные — из локальной
базы + серверного зеркала по `journalToken` ([protocol.md](protocol.md) §7).

Журнал доступен **всем** членам семьи, у кого есть пара, и не редактируется из приложения.
Это сознательно: прозрачность работает только тогда, когда её нельзя выключить.

## 6. Чек-лист приёмки

- [ ] Присутствие обновляется за ≤ 3 с после появления/пропадания бабушки в сети.
- [ ] Запрос помощи доходит до спящего телефона бабушки (FCM) за ≤ 10 с.
- [ ] Отказ и таймаут показываются нейтрально, без побуждающих кнопок.
- [ ] Лимит запросов виден помощнику до того, как он упрётся в ошибку.
- [ ] Указатель попадает в ту же точку экрана, что и на устройстве бабушки (±2 % размера).
- [ ] Веб-панель проигрывает полный сценарий 1-2-3 с проверкой MAC.
- [ ] Секрет пары в веб-панели невозможно прочитать из консоли браузера.
